# /faq/guides — баг переключения вкладок, фикс v5 (2026-10-30)

Файл: `2026-10-30_faq-guides-tabswitch-v5.diff` — только `FaqGuidesPage.vue`, отдельно от v4
(который чинил только 404, не трогал код компонента). **Не запушено, не задеплоено.** Ждёт
вашего ревью.

## Баг

Страница `/faq/guides`. Клик по любой вкладке («Создать курс» / «Бесплатный эфир» /
«Мероприятие» / «Клуб» / «Деньги и вывод»): сама кнопка подсвечивается верно
(`aria-selected` переключается на кликнутую), но видимое содержимое НЕ меняется — остаётся
секция, активная при загрузке страницы (обычно «Создать курс»). Воспроизводится и по прямому
клику, и по URL-якорю после первого клика.

Обнаружен **после** деплоя `4d50728` (FAQ CMS) — не связан с v4 (`vite.config.js`, только 404).

## Причина (по диагностике)

1. Сначала нашёл и исправил отдельный, независимый баг: `history.replaceState(null,'','#'+g)`
   резолвился не от текущего пути `/faq/guides/`, а от `<base href="/">` в шаблоне страницы —
   URL терял `/faq/guides` (становился `/#stream`). Эта правка (`location.pathname + '#' + g`)
   нужна сама по себе, но переключение контента она не чинила.
2. Основная причина — комбинация `v-for="g in GUIDE_ORDER"` + `v-show="activeGuide === g"` на
   ОДНОМ `<section>`. Подтвердил через: (а) минимальный локальный репро — урезал содержимое
   секции до `{{ g }}` — заработало; постепенно возвращал контент обратно — баг вернулся;
   (б) прочитал скомпилированный Rolldown-чанк прямо с прода — директива `v-show`
   (`[[m, K.value===e]]`) синтаксически верна, ошибок в консоли нет; (в) решающий тест — вывел
   `activeGuide` и `g` рядом текстом: после клика `activeGuide` корректно показывал новое
   значение, а `g` (переменная цикла) внутри ЭТОЙ конкретной секции оставалась замороженной на
   исходном значении. Это Rolldown-специфичное поведение (проект использует Vite+Rolldown, не
   классический Rollup — более новый, менее обкатанный бандлер).

## Фикс

- Вынес `v-for` на отдельный `<template>`, переключил `v-show` → `v-if` на `<section>` —
  реальный mount/unmount вместо toggle display. Это другой механизм патчинга, обходит
  конкретное взаимодействие v-show+v-for, которое ломалось.
- Побочный эффект: с `v-if` в DOM существует только активная секция → `IntersectionObserver`
  для шагов других гайдов настраивался на несуществующие узлы. Переписал на пересоздание
  наблюдателя при каждой смене `activeGuide` (`watch(activeGuide, ...)` + `disconnect()`
  предыдущего) вместо разового сетапа на всех 5 гайдов при маунте.
- Плюс правка URL из п.1 выше (`location.pathname + '#' + g`).
