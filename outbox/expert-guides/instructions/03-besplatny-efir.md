# Как провести бесплатный эфир

> Проверено по коду: `StreamsPage.vue` (страница эфиров `/streams`), `streamsApi.js`, `peertubeLive.js`.
> Вести эфир могут роли **«Спикер»** и **«Учебное заведение»**.

## Шаги (формат «Один ведущий», с телефона/OBS)
1. Откройте раздел **«Трансляции»** (`/streams`) и в блоке **«Начать трансляцию»** нажмите кнопку **«Начать трансляцию»**.
2. Заполните **«Название»** (3–120 символов), при желании — **«Описание»** и **«Обложка (необязательно)»**.
3. При необходимости задайте **«Дата и время эфира (необязательно)»** — эфир станет запланированным и будет виден зрителям с отметкой времени.
4. В **«Формат эфира»** выберите **«Один ведущий»**.
5. В **«Доступ»** выберите **«Бесплатно»**.
6. Нажмите **«Создать эфир»**.
7. В карточке **«Данные для OBS»** скопируйте **«Сервер (URL)»** и **«Ключ потока»** и укажите их в OBS/приложении для трансляции (ключ никому не передавайте).
8. Когда готовы — нажмите **«Я в эфире»** и начните вещание; по окончании — **«Завершить»**.

## Что получится
- **Вход зрителей:** эфир публичный. Чтобы **смотреть** бесплатный эфир, вход в аккаунт не нужен — зритель открывает `/streams`, нажимает на карточку. Запланированные эфиры показываются с отметкой **«🕐 Начало: …»** и статусом «Запланирован»; до старта — заглушка «Эфир ещё не начался».
- **Чат:** блок **«Чат эфира»** доступен всем зрителям бесплатного эфира (читать — всем; писать — после входа в аккаунт). Автор эфира может удалять любые сообщения.
- **Запись:** у эфира сохраняется запись (replay). После **«Завершить»** на странице эфира появляется «Запись обрабатывается…», затем запись проигрывается там же («Смотреть запись»). Для бесплатного эфира запись **не** превращается в отдельный курс.
- Кнопка **«🔗 Поделиться»** даёт ссылку вида `…/streams?stream=<id>`.

## Частые ошибки
- **У бесплатного эфира нет «Общего чата трансляции» и опции «Запись как отдельный курс»** — эти два пункта доступны только для платного эфира. Обычный чат эфира у бесплатного работает (не путать с платным групповым чатом).
- **Статус ставится вручную** — если не нажать «Я в эфире», эфир не перейдёт в статус «в эфире» (и пуш-уведомление о старте не уйдёт).
- **После создания нельзя переключить бесплатный↔платный** — меняются только название/описание/обложка/время («Редактировать»).
- **Ключ потока — секрет**, предупреждение в интерфейсе: «Никому не передавайте ключ потока…».
- Со-ведущие (формат «Со-ведущие») — другой сценарий: без OBS, через кнопки «Начать эфир»/«Войти в эфир» и приглашение по e-mail; это отдельная тема.
