# Финансы: где видны продажи, как и когда выводятся деньги, какие комиссии

> Проверено по коду: `MyFinancePage.vue` + `financeComponents.js` (страница «Финансы» `/my_finanse`), `SuperadminPage.vue`, миграция `pending_superadmin_s4_money_ledger_commission.sql`.

## Где видны продажи и баланс
1. Откройте раздел **«Финансы»** (`/my_finanse`).
2. Вверху — карточка **«Доступно для вывода»** (ваш баланс).
3. Три вкладки: **«История заказов»** (ваши покупки), **«История продаж»** (ваши продажи), **«Вывод средств»**.
4. Во вкладке **«История продаж»** — строка **«Продано на сумму: … руб.»** и таблица с колонками **«Наименование товара» / «Покупатель» / «Сумма» / «Дата»**, с фильтрами по категории и датам.

## Какие комиссии
- Комиссия **индивидуальная для каждого эксперта** и её назначает **суперадмин** (`/superadmin` → вкладка «Комиссия», «Изменить комиссию автора»). Меняется **только на будущие продажи** — прошлые начисления не пересчитываются.
- Площадка удерживает **плавающую комиссию 6–18%**, то есть **эксперту остаётся 82–94%** с продажи (конкретный процент зависит от договорённости с площадкой). В баланс зачисляется доля эксперта по каждой продаже.

## Как вывести деньги
1. Откройте вкладку **«Вывод средств»**.
2. Сначала заполните **«Платёжные реквизиты»**: **«Тип получателя»** (Самозанятый / ИП / ООО), ФИО или наименование, **ИНН**, при необходимости КПП/ОГРН, **Банк**, **БИК**, **Расчётный счёт** (можно автозаполнить кнопками **«Найти по ИНН»/«Найти по БИК»**) и нажмите **«Сохранить реквизиты»**.
3. В карточке вывода (**«Доступно к выводу: … ₽»**) укажите **«Сумма»** и нажмите **«Запросить вывод»**.
4. Появится сообщение **«Заявка создана. Выплата будет проведена вручную после проверки»**; заявки видны в **«История заявок»** со статусом «Запрошено» → «Подтверждено»/«Отклонено».

## Что получится
- Заявку рассматривает **суперадмин вручную** (`/superadmin` → «Выплаты») и переводит деньги через банк; статус заявки меняется, может быть комментарий администратора.
- Баланс и продажи начисляются автоматически после успешной оплаты покупателем (через платёжную систему и фоновую обработку).

## Частые ошибки
- **Без сохранённых реквизитов вывод недоступен** — сначала «Сохранить реквизиты» («Сначала сохраните платёжные реквизиты»).
- **Нельзя вывести больше баланса** — проверка «Недостаточно средств на балансе».
- Изменение комиссии суперадмином влияет **только на будущие** продажи, не на прошлые.
