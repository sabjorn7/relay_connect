Ограничения временного подхода:
1. Браузер остаётся источником запроса к Prodamus. Подмену subscription/order_id
   пользователем на этом этапе нельзя исключить одной RPC создания заказа.
   Это НЕ полное выполнение требования защиты платёжных параметров end-to-end.
2. Фактическая цена/активность плана Prodamus без вызова провайдера не проверена.
3. Повторные нажатия не создают новый неоплаченный заказ, но могут повторить запрос
   платёжной ссылки. Клиентский busy-guard не добавлен.
4. pageUrl больше не сохраняется. Проверенный callback не нуждается в pageUrl;
   другие внешние потребители этого поля не проверены.
5. В legacy JSON уже есть credential платёжного механизма. Не выносился в новые
   файлы и не менялся. Не распространять полный однострочный diff публично.
6. Изменения WeWeb JSON могут быть потеряны при повторном экспорте.
7. Общая браузерная регрессия checkout и полный E2E клуба остаются перед публикацией.
