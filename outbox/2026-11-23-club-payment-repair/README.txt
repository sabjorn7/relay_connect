Сначала прочитайте REPORT.txt: общий браузерный тест не пройден; временный
браузерный запрос Prodamus не защищает платёжные параметры end-to-end.

Применение только в чистом локальном checkout указанной базы:
  git apply --check /путь/changes.diff
  git apply /путь/changes.diff
  python3 scripts/apply-club-subscription-payment.py
Скрипт проверяет SHA-256 исходного и итогового JSON, останавливается при отличиях
и допускает повторный запуск без повторной правки. SQL автоматически НЕ применяется.
JSON целиком не включён: он содержит существующий credential. Скрипт сохраняет
его на месте, не содержит и не печатает значение.

Файлы SQL, откат и тесты также приложены отдельно для просмотра.
Сборка/production/коммиты MeetGuru не выполняются при применении diff.
