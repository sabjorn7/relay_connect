# Импорт 9 отзывов в курс «Вводный курс по кинезиологии» (slug vvodnyy-seminar-po-kineziologii)

Только анализ + SQL на ревью. Ничего не применял. Тексты отзывов не менял.

## 1. Как хранятся и показываются отзывы/оценки
- `course.rating` — jsonb-массив, элемент: `{ "user_id", "rating" (1–5), "date" (ISO) }`.
- `course.comment` — jsonb-массив, элемент: `{ "user_id", "name", "photo", "comment", "date" (ISO) }`.
- CoursePage.vue:
  - `reviews` = `course.comment`, где `comment` непустой; на карточке: **текст** = `r.comment`, **автор** = `r.name || 'Ученик'`, **дата** = `fmtDate(r.date)` → `new Date(iso).toLocaleDateString('ru-RU',{day,month:long,year})` = «3 августа 2025».
  - **Звёзды** на карточке = `ratingByUser[r.user_id]` — рейтинг берётся из `course.rating` **по совпадению `user_id`**. Если у отзыва нет `user_id` (или нет парной записи в rating) — звёзды не показываются (но оценка всё равно учитывается в средней).
  - **Средняя** = среднее `rating[].rating`; на странице `avg.toFixed(1)` → «4.8». **Кол-во** = длина `rating`.
- MyCoursePage.vue пишет отзыв так же: rating `{user_id:myId, rating, date}` (один на пользователя, upsert), comment `{user_id, name, photo, comment, date}`.

## 2. Как добавляем без фейковых аккаунтов
- **Аккаунты НЕ создаются.** `user_id = 'tg-import-vvk-N'` — это строка-метка **внутри jsonb**, не строка в `users`/`auth`. Нужна только чтобы звёзды привязались к карточке (CoursePage ищет рейтинг по `user_id`).
- **Имя** — текстом в `comment.name`. `photo = null` (аватар-заглушка).
- **`source: "telegram"`** — машинная пометка происхождения в каждой записи (rating и comment).
  ⚠️ Фронт сейчас поле `source` **не рендерит** — видимой подписи «отзыв перенесён из Telegram» на странице не будет. Если нужна **видимая** пометка — два варианта (на твоё решение, отдельно): (а) маленькая правка CoursePage: показывать `source`; (б) дописать в `name` (но это изменит отображаемое имя). Я НЕ дописывал в имя и НЕ трогал тексты.
- Append через `coalesce(...) || jsonb_build_array(...)` — существующие отзывы/оценки не затираются. Идемпотентно (guard по `tg-import-vvk-1`). Откат удаляет ровно записи с `user_id LIKE 'tg-import-vvk-%'`.
