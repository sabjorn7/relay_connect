## Результат

Вместо старого высокого блока — одна строка: скрепка, микрофон, компактное поле «Написать сообщение…», круглая кнопка с тем же SVG-самолётиком, что в ChatsPage. Аватар композера и старый отдельный выбор фото скрыты при включённой capability вложений; изображения выбираются существующей скрепкой. Обычные чаты не менялись.

Поле осталось исходным WeWeb-input, включая сохранение значения и переносов строк. Новая доступная native button вызывает только click старой кнопки, то есть уже существующий WeWeb workflow. Копии INSERT или другого серверного обработчика нет. Пустой/пробельный текст не отправляется, кнопка отключается; после успешной отправки исходный workflow очищает поле. Прежние обработчики вложений, MediaRecorder, MP3 fallback, retry, просмотра/удаления сохранены.

## Применение и откат пакета

`frontend.diff` содержит только три кодовых файла, без контекстных строк. JSON представлен минимальным `page-changes.json` и точным проверяющим `apply-page.py`, чтобы не перепубликовывать всю экспортированную страницу. До применения сверить SHA из manifest.

В отдельной копии базы:

```sh
git apply --unidiff-zero --check /path/to/frontend.diff
git apply --unidiff-zero /path/to/frontend.diff
python3 /path/to/apply-page.py /path/to/app-copy
```

Далее скопировать tests из пакета в tests копии и выполнить Vite build, `club-composer-full.browser.mjs`, `club-composer.browser.mjs`, `local-regression-group-chat-authors.browser.mjs` с `PLAYWRIGHT_MODULE` на установленный Playwright. Использовались Node 24.14.0, установленный Chrome и Playwright WebKit; новые зависимости не устанавливались.

Локальный откат: `git apply --unidiff-zero --reverse frontend.diff` и `python3 apply-page.py /path/to/app-copy --reverse`. Скрипт отказывается перезаписывать страницу при другом SHA. Публикация и production-откат — только отдельным согласованным frontend-релизом через Deploy App; серверных действий не требуется.

## Ограничения

Это небольшая UI-адаптация существующего WeWeb-композера: скрытая оригинальная кнопка сохраняется в DOM, чтобы использовать прежний workflow, а native-кнопка делегирует ей click. При изменении UUID/структуры экспортом WeWeb необходим повтор этих маршрутных тестов. Никаких runtime observers, polling, нового сервиса или нового API нет.

При выключенной capability остаётся legacy-композер без нового add-on; функциональные ограничения сервера не обходятся. Переносы строк сохраняются; компактное поле прокручивается при длинном многострочном тексте. Автоувеличение поля и новая семантика Enter в textarea не добавлялись. Для текущих доступных Chrome/WebKit кандидат готов к согласованию публикации.
