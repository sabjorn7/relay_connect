## Что требует отдельного согласования

1. Применить предложенный SDK diff **только к отдельной локальной копии исходников**, собрать из неё тестовый пакет и проверить матрицу. Не редактировать установленный `node_modules`, не менять SDK рабочего проекта. Патч публикуется здесь для ревью до этой операции.
2. Независимо согласовать Node24 в CI. На текущем этапе менять workflow не требуется и не разрешено автоматически.

`prepare-diff.py <путь к src/GoTrueClient.ts версии 2.119.2> <новый путь.diff>` только читает исходник, проверяет SHA и генерирует diff/manifest. Исходник не перезаписывает. Не содержит установки, запуска SDK или изменения CI.

Дальнейший выпуск — только после PASS на собранной зависимости, браузерных регрессий и отдельного разрешения. Предыдущие PASS не доказывают корректность нового предложения.
