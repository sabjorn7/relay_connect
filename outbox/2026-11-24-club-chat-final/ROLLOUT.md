## Откат

Выполнить согласованный server/disable.sql, выключить PUSH_CLUB_ENABLED; вернуть сохранённые frontend и Edge версии штатными механизмами. Новые nullable поля/private bucket оставить совместимыми со старым frontend. Не удалять сообщения/файлы/подписки/историю. Не делать bucket публичным, не менять RLS существующих таблиц. Нет автоматического изменения старых политик или ключей.

Runtime WeWeb и экспортированный JSON содержат точечные правки; при повторном экспорте их нужно сохранить. Page script проверяет исходный SHA и меняет только два аргумента get_chat, без повторной сериализации всей страницы.
