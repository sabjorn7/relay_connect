# Реальные PWA-устройства — только после разрешения

Получатель: caa712f8-f5e8-484d-b46d-c56205f52ed1, до трёх активных устройств. Перед тестом согласовать конкретные устройства и время; получить подтверждение разрешения уведомлений. Физические Android/iOS/Safari сейчас NOT TESTED.

1. После одобрения установки и включения убедиться в единственном recipient UUID и клубе. Глобальный allowlist не менять.
2. Сообщение создаёт другой согласованный участник: собственное сообщение получателя уведомления не вызывает. Согласовать текст и создание записи в существующем клубе заранее.
3. При свёрнутой PWA проверить обезличенный push и переход по нажатию в нужный клуб. Зафиксировать время/тип устройства/результат без endpoint и токенов. HTTP201 не считать доказательством появления уведомления.
4. Согласованно опубликовать пост; получить второй generic push. При редактировании обоих объектов повтора быть не должно. Не создавать пост от имени другого пользователя.
5. Настройки send_notif и исключение отправителя проверены локально; реальные настройки аккаунтов без разрешения не менять. Другие аккаунты не должны получать новые клубные push.
6. Обычные chat push остаются неизменны; реальную отправку для их проверки согласовать отдельно.
7. При ошибке вызвать disable, сохранить обезличенный результат. Пользовательские данные не удалять. Не включать массовую доставку.
