## Подтверждено

Повторный существующий одобренный production status: candidate_matches=true, runtime running, club_env_enabled=false, оба триггера D, global allowlist all. Никаких новых скриптов на сервер не загружено. Sudo сообщил предупреждение разрешения имени sb, сам status завершился 0.

Права mgdeploy позволяют только mg-deploy с административно одобренным SHA. Полная текущая Compose-конфигурация и main worker этим доступом не читаются. По ранее проверенному main окружение проходит через Deno.env.toObject → envVars → userWorkers.create; helper ключа оплаты возвращает envVars других функций без изменения. Это историческое свидетельство, не новая проверка исходника production.

**Остаётся блокер готовности к включению:** точный текущий источник передачи PUSH_CLUB_ENABLED в контейнер. Новый read-only status выдаёт SHA main/helper, структурные булевы признаки и наличие/boolean флага в эффективной Compose-конфигурации и работающем контейнере. Значения других переменных, содержимое исходников и stderr не выводятся. status требует отдельного одобрения SHA администратором. Он ничего не меняет; если Compose не удаётся разрешить, явно сообщает read_or_resolution_unavailable. Команда docker restart не обновляет окружение существующего контейнера; этот пакет не пытается включить env через restart.

Уже исполняющиеся/доставленные push отозвать невозможно.
Install и аварийный disable перезапускают общий Edge Runtime: кратко затронут все Edge Functions. Сейчас restart не выполнялся. После disable возобновление требует отдельно проверенного восстановления env-gate; enable сам его не восстанавливает. Не возвращать широкий baseline helper при true gate.
