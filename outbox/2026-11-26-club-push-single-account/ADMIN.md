# Административный запуск — после отдельного согласования

Сейчас ничего не устанавливать и не отправлять. Файлы имеют суффикс r2, предыдущие scripts не подменяются. SHA — WRAPPER-SHA256.txt; все файлы — SHA256SUMS.

1. После согласования передать wrappers в /home/mgdeploy/staging. Администратор проверяет sha256sum каждого файла и одобряет точные строки SHA/имени в /etc/mg-deploy/approved.sha. Не обходить проверку SHA.
2. Сначала разрешить только чтение:

```sh
/usr/local/sbin/mg-deploy meetguru-club-push-pilot-status-20261126-r2.sh
```

Проверить env_path_evidence, Compose mapping, main SHA и цепочку envVars. Одни строковые признаки не являются полным доказательством семантики. При неподтверждённой схеме остановиться, получить только безопасный структурный фрагмент через администратора. Секреты не копировать. Перед install: клубный flag false, оба triggers D, исходные SHA совпадают.

3. После отдельного разрешения установить ограничивающий helper:

```sh
/usr/local/sbin/mg-deploy meetguru-club-push-pilot-install-20261126-r2.sh
```

Ожидать INSTALLED_DISABLED, RECIPIENT_COUNT=1. Backup: /var/lib/mg-deploy/club-push-pilot-20261126-r2. Сохранить BACKUP/exit code. Общий Edge Runtime кратко перезапускается. Если baseline не совпадает — остановиться, не перезаписывать чужие изменения.

4. Только после проверки status и отдельного разрешения на уведомления обеспечить PUSH_CLUB_ENABLED=true через фактически подтверждённую серверную конфигурацию. Точная команда пока не установлена; не подменять её предположительной правкой .env. Docker restart не меняет env контейнера. Сначала scoped helper, затем передача true flag, затем triggers:

```sh
/usr/local/sbin/mg-deploy meetguru-club-push-pilot-enable-20261126-r2.sh
```

Enable не меняет окружение, не создаёт тестовые записи. После него реальные новые события клуба могут уведомлять выбранный аккаунт на трёх устройствах. Если flag false или source drift — остановка до SQL. Не выполнять enable.proposed.sql отдельно, обходя guards.

5. Немедленное отключение после отдельного согласования эксплуатации:

```sh
/usr/local/sbin/mg-deploy meetguru-club-push-pilot-disable-20261126-r2.sh
```

Ожидать DISABLED_CLUB_ONLY и D/D. Только клубный gate фиксируется false в index, общий Edge Runtime перезапускается. Данные/подписки не удаляются. При неизвестном index триггеры выключаются, чужой код не перезаписывается: администратору потребуется отдельно закрыть gate для queued callbacks. Уже доставленные push не отзываются.

## Откат

Install при ошибке возвращает backup helper. Для отката после включения сначала disable и проверка D/false. Не восстанавливать старый неограниченный helper с включённым gate. Возобновление после аварийного disable требует отдельно проверенного возвращения исходного env-gate, согласованного scope и нового одобрения. Никаких удалений сообщений, постов, подписок или истории.
