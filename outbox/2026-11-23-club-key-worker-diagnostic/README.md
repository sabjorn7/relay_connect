Проверка из этого каталога:

```bash
sha256sum -c SHA256SUMS
node diagnostic.test.mjs
```

Результат: **17 PASS** на синтетическом Deno API в Node. Это не выполнение на реальном Edge Runtime 0.1.0 / Deno 1.45.2.

Установка только после отдельного согласования через существующий административный механизм. Этот пакет ничего автоматически не устанавливает. Не применять SQL, не менять n8n, frontend или значение ключа.

После согласованной установки одна анонимная проверка 401 запускает worker и формирует запись `club_key_load_v1`. Запись содержит только булевы результаты, источник ключа и тип ошибки из фиксированного списка. Ключ, его длина, части, хеш, текст исключения и stack не выводятся.

Откат диагностики: после сверки с резервной копией вернуть только исходный `checkout-pay-link/index.ts` и согласованным способом перезагрузить код Edge Runtime. Другие файлы и ключ не менять.

Окончательное исправление передачи ключа выбирается после результата реального worker; предположение о файловом API не выдаётся за установленную причину.
