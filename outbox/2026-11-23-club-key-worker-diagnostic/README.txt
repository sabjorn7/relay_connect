MeetGuru — временная диагностика ключа внутри checkout-pay-link worker.
Статус: только локальный пакет; production НЕ изменён; root-причина пока не подтверждена.

Состав: index.ts — временная замена только точки входа checkout-pay-link.
handler.mjs, clubPayment.mjs, SQL, n8n, frontend и значение ключа не меняются.
Перед установкой сверить index.ts с BASELINE.sha256, сохранить root-only резервную копию.
Установка/перезапуск Edge Runtime требуют отдельного согласования; здесь не выполнялись.

Запись club_key_load_v1 выводится один раз на запуск worker, не на каждый запрос.
Поля env_present/env_nonempty/env_error описывают PRODAMUS_SECRET_KEY.
file_read/file_error — чтение .prodamus-key.json внутри worker.
json_valid/json_error/json_object — результат разбора и форма JSON.
key_present/key_nonempty — наличие собственного поля key и непустой строки.
source — env/file/none, с сохранением прежнего приоритета и исходного значения.
Типы ошибок ограничены фиксированным списком; неизвестный тип — Other.
Не выводятся секреты, их части, длина, хеш, сообщения ошибок, stack, URL и пути.
Даже при наличии env выполняется однократная проверка файла для полноты диагностики.
Диагностика не делает сетевых запросов, не создаёт заказов и не обращается к Prodamus.

После отдельного одобрения и установки вызвать один анонимный POST {}:
curl --max-time 20 -sS -o /dev/null -w '%{http_code}\n' -X POST -H 'Content-Type: application/json' --data '{}' https://app.meetgu.ru/sb/functions/v1/checkout-pay-link
Ожидается 401. Для диагностики достаточно запуска worker; авторизация/покупка не нужны.
Администратор извлекает ТОЛЬКО JSON с event=club_key_load_v1 из журнала Edge Runtime.
Не присылать полный docker inspect, env, файл ключа или необработанные журналы.

Интерпретация:
- env_nonempty=true: ключ в окружении существует; отдельно проверить file-поля.
- env_nonempty=false + file_error: загрузка файла не удалась в worker; точный тип указан.
- file_read=true + json_valid=false: ошибка JSON, не проблема Prodamus или SQL.
- json_valid=true + key_nonempty=false: неверная форма файла/поля key.
- key_nonempty=true + source=file: гипотеза отсутствующего ключа НЕ подтверждена;
  передачу ключа вслепую не менять.

Минимальное исправление выбирается ПОСЛЕ записи из реального worker.
Если файловый API недоступен: передавать прежний ключ штатным envVars только worker
checkout-pay-link из защищённого серверного источника, без глобального распространения.
Если ошибка JSON/поля: исправить только формат серверного файла, сохранив ключ.
Если проблема пути: исправить только путь чтения; не расширять права файла.
Не заменять синхронный API асинхронным наугад: это не доказывает доступность файла.
Убрать временную диагностику после подтверждения и проверки минимального исправления.
