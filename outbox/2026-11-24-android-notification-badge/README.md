# Android notification badge

Локально подготовлено, production не менялся. База d64d36b7a6e678a64cb80118f6ed4315f000a3cd; ветка fix/android-notification-badge-20261124.

Причина квадрата: serviceworker.js использует apple-touch-180.png (непрозрачный PNG) одновременно как icon и badge. Android превращает badge в монохромную alpha-маску.

Исправление: новая notification-badge-mg-v2.png, 96×96, белые буквы и прозрачный фон; изменена одна строка badge в showNotification. Цветной icon, manifest, маршрутизация уведомлений, payload, подписки и кеш-стратегия не изменяются.

Изображение изготовлено напрямую из alpha-маски предоставленного пользователем Frame 34733.png: обрезаны прозрачные поля, знак вписан в 80px внутри 96px canvas, цвет заменён на белый с сохранением прозрачности. Неудачные генеративные версии и первоначальный нарисованный вариант v1 не входят в diff. Итог 1673 байта; 7254 полностью прозрачных пикселя и 1962 с ненулевой alpha, все видимые пиксели белые. Превью 96 и 24px приложено.

Проверки: alpha/размер/одноцветность PASS; обработчик push в изолированном Node VM PASS для пустого, битого payload, сообщения и старта трансляции. icon, link и tag сохранены. Vite build без postbuild PASS; git diff --check PASS. Физическое отображение в системной шторке Android NOT TESTED — требуется проверка на устройстве после согласованного релиза.

Публикация: после разрешения обычный Deploy App; CI сам обновляет версию SW. После установки обновлённого service worker проверить НОВОЕ уведомление. Уже показанные уведомления не меняются, обновление SW на конкретном устройстве может потребовать повторного открытия PWA. Логотип приложения на домашнем экране остаётся прежним.
