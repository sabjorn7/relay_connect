# Порядок внедрения и откат — только после отдельного разрешения

1. Закрыть prerequisites SERVER-PLAN.md; согласовать конечный SQL/RLS/Storage/event diff. Текущий draft автоматически не применять.
2. Сверить свежий main и фактические серверные версии. Сохранить frontend SHA, определения затрагиваемых функций/политик/триггеров, конфигурацию bucket и Edge backup. Не сохранять секреты в outbox.
3. На согласованном стенде применить утверждённую схему и access policies с флагами false, проверить легитимные действия участника/владельца/модератора и отказ гостю/постороннему. В production — только отдельным разрешённым административным шагом.
4. Установить утверждённую серверную часть существующей web-push-send с PUSH_CLUB_ENABLED=false. Затем frontend. Frontend projection требует новых колонок заранее.
5. Проверить прежние текст/фото/delete, disabled addon, обычные чаты, отсутствие реальных рассылок. После отдельного разрешения включать attachments и club push по одному, сначала существующий allowlist. Не включать глобальный allowAll ради проверки.
6. Проверить реальное устройство и отсутствие закрытого текста на lock screen. Нет разрешения отправлять это сейчас.

Локальное воспроизведение frontend на чистой базе:
```sh
git apply --check /path/to/outbox/frontend/changes.diff
git apply /path/to/outbox/frontend/changes.diff
python3 /path/to/outbox/frontend/apply-page.py
```
Полный список файлов — FILES.json. Изменения WeWeb renderer/JSON могут быть перезаписаны новым экспортом; сохранить override при экспорте.

При неисправности: штатным согласованным механизмом выключить PUSH_CLUB_ENABLED и отдельные SQL feature flags (DISABLE.sql). Вернуть сохранённый frontend и предыдущую Edge Function. Новые nullable колонки и private bucket оставить: старый frontend их игнорирует. Не удалять историю, вложения, подписки, платежи. Не делать bucket публичным и не выключать RLS ради отката. Откат approved access policy только к заранее сохранённым определениям и после оценки утечки старых данных; текущая небезопасная baseline не является безопасным автоматическим rollback.

Сейчас ничего откатывать не требуется: production не менялся, размещены только артефакты в relay_connect.
