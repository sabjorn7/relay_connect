## Подготовлено

- Полный `/club` проверен с реальными WeWeb-компонентами и локальными API-моками, а не только изолированными пузырьками: история, существующая отправка текста, подтверждение удаления, реальный popup фотографий, мобильная/десктопная компоновка.
- История ограничена текущим club ID. Ранее запрос get_chat не содержал этого фильтра. Это фильтр интерфейса, не замена RLS.
- Исправлено удержание последнего сообщения при асинхронном изменении высоты списка. Только два существующих club-list UUID; после пользовательского wheel/touch/pointer/key ввода удержание выключается, до возвращения вниз. Resize/MutationObserver отключаются при размонтировании.
- Сохранён renderer прошлого пакета: автор/аватар/инициалы, профиль по ID, локальные дата/время, безопасные ссылки и существующий ChatLinkPreview.
- Файлы/голосовые — отдельное дополнение к прежнему composer. Используются существующие validateFile, ACCEPT_ATTR, formatBytes, pickAudioFormat, encodeBlobToMp3 и VoiceMessagePlayer. Общий чат и его uploadChatFile не изменены.
- Новый файл отправляется исключительно в `club-chat-private`, upsert выключен. RPC назначает автора через auth.uid(). Повтор после сетевой ошибки сохраняет request UUID; повторная загрузка после успешного upload не нужна.
- Чтение по короткой signed URL (60 секунд), без публичного fallback. URL убирается из интерфейса при logout/смене сообщения/истечении локального срока. Уже выданная ссылка может оставаться действующей до серверного истечения 60 секунд.
- UI дополнения скрыт, если `club_chat_capabilities` отсутствует, ошибается или возвращает false. После logout очищаются pending и локальное аудио, запись прекращается.
