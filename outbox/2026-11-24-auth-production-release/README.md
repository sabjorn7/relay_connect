## Последствия и откат

После обновления требуется повторный вход: старые refresh tokens не мигрируют в auth-v2. Ограничения браузеров без Web Locks и старых вкладок остаются теми же, что в согласованном пакете.

Точка возврата: `e062265304688b744b36b8f2ea021b8270c641ad`. При подтверждённой необходимости — отдельная ветка от актуального main, `git revert 1d8364f7721cb0e9eeefaad815f1d1469af6ead7`, проверка diff/сборки, затем согласованный PR/merge и штатный Deploy App. Не выполнять reset/force push или ручную серверную установку. При конфликте остановиться.

Откат к legacy-коду может прочитать оставшуюся старую сессию другого выбранного ранее аккаунта; возврат кода не очищает browser storage. Учитывать это перед откатом, как описано в [согласованной инструкции](https://github.com/sabjorn7/relay_connect/blob/0917830/outbox/2026-11-24-auth-unified-release/DEPLOYMENT.md). Откат сейчас не выполнялся.

SQL, RLS, backend, платёжные механизмы и настройки диагностики не изменялись. Node изменён только согласованной строкой существующего Deploy App. Основная рабочая копия пользователя не изменялась.
