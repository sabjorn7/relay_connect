## Блокер

Имеющийся public.execute_sql оборачивает запрос в SELECT ... FROM (<query>), что позволяет читать данные, но не применять DDL-миграцию. Обходить это ограничение или подменять функции для выполнения DDL не предпринималось.

## Что требуется для продолжения

Предпочтительный существующий путь — владелец применяет supabase/migrations/pending_stream_video_quality.sql штатным production PostgreSQL-доступом после защищённой резервной копии и повторной проверки отсутствия live/Egress. Затем выполняет:

```sql
NOTIFY pgrst, 'reload schema';
```

Альтернатива — предоставить уже существующий разрешённый административный способ применения миграции и создания backup без передачи пароля в чат. Новые привилегированные RPC, изменения конфигурации MCP и создание credentials автоматически не выполняются.

Дальнейшая последовательность разрешённого внедрения сохраняется: проверка схемы/default HD/Full HD=false → защищённый backup и контроль template/образов/mounts → замена только candidate orchestrator и template с перезапуском только live-orchestrator → проверки API → завершение изолированного frontend-релиза/тестов → commit/push и ожидание штатного Deploy App → безопасные проверки сайта без запуска эфира.

## Full HD и откат

Оставить full_hd_enabled=false. Существующий флаг глобальный, не per-user allowlist: UPDATE full_hd_enabled=true откроет настройку всем, поэтому это не инструкция для ограниченного production-теста. Для теста нужен отдельно выбранный механизм допуска конкретного организатора/эфира; сейчас флаг не менять.

Существующий rollback SQL только запрещает новые Full HD, но не возвращает старый код. Технический rollback требует защищённой копии исходников/template, параметров контейнера и доступного старого frontend-артефакта; перед фактической записью это ещё необходимо проверить. Не удалять additive SQL, историю или снимки запущенных потоков. Старый orchestrator не возвращать при активных Full HD.

Текущее состояние: прежний production работает, ничего откатывать не требуется. Готовность нового интерфейса на production к ручному тестированию пока не заявляется.
